Data Lineage Platform

DAO (SOO) to YXY (SOR) to AOC (APP) to MIS Report, with a catalog and independent controls

Six applications

Each is its own FastAPI application. The pipeline moves the records through DAO, YXY, AOC and MIS Report, and the controls app checks the result against the source.

Source data and parameters

The app starts with built-in sample data. Upload your own CSV files to run the same transformations on them. The parameters are the YXY filter values.
